# Chat station 

एक All-in-One Converter app बनाना है जो Google पर सबसे ज्यादा rank करे। PDF, JPG, PNG, WebP जितने भी कनवर्टर होते हैं वह सब एक साथ (PDF to JPG, JPG to PDF, PNG to JPG, WebP, Image Compressor, Resizer)। 

सर्वर खर्चा और होस्टिंग खर्चा बिल्कुल न आए या जीरो आए — सारा कन्वर्जन 100% यूजर के ब्राउज़र में (Client-side / Canvas / pdf-lib) हो। कोई फाइल सर्वर पर अपलोड न हो, जिससे जीरो सर्वर कॉस्ट रहे, सुपरफास्ट स्पीड मिले और प्राइवेसी पूरी रहे। हाई SEO रैंकिंग और मोनेटाइजेशन के लिए तैयार।
